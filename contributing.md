# Contribution Guidelines

Open a pull request to add a link. Before you open it, check these rules:

- Add one link per pull request.
- Add the link to the section that fits it, at the bottom of that section.
- Use this format: `- [Name](https://link) - Description.` The description starts with a capital letter and ends with a period.
- Link to resources that are maintained and that work with a released version of Switch.
- Do not add links that are already in the list.
- Check your spelling and grammar.

Open an issue to suggest a new section or to report a broken link.
